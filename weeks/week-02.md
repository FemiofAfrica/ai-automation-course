# Week 2: Claude & Prompt Engineering for Marketing

**Session Length:** ~3 hours
**Objective:** Master Claude for marketing content, analysis, and structured outputs. Understand when to use the API vs chat interface.

---

## Key Concepts Covered

- Claude model lineup for marketing: Haiku vs Sonnet vs Opus
- Anatomy of a great marketing prompt (persona, context, task, constraints, output)
- The 5-prompt marketing workflow: Brief → Research → Draft → Personalize → Critique
- Claude Projects, Custom Instructions, Artifacts for marketing
- API conceptual overview (no coding)

## Deliverable

**Marketing Brief Generator** — A Claude project template + reusable prompt library for campaign briefs, product launches, agency briefs, competitor analysis, and ABM personalization.

## Prerequisites

- Claude.ai Pro account
- 3 real marketing challenges ready
