# Week 3: n8n — Marketing Workflow Automation

**Session Length:** ~3 hours
**Objective:** Connect your entire marketing stack without a developer. Build automated workflows with AI nodes, error handling, and real tool integrations.

---

## Key Concepts Covered

- n8n architecture: triggers, nodes, data flow
- Marketing workflows:
  1. Social Content Repurposing Engine
  2. Lead Enrichment Pipeline
  3. Campaign Operations Pipeline
  4. Automated Performance Reporting
- The Claude-n8n bridge: structured prompting in workflows
- Error handling, retries, cost management

## Deliverable

**Content Distribution Pipeline** — Notion → Claude generates platform-specific variants → schedule posts → log performance → report back to team.

## Prerequisites

- Docker Desktop installed
- Access to 2+ marketing tools you use daily
- 1 manual workflow involving 3+ tools
