# Week 4: The Marketing Operating System

**Session Length:** ~3 hours
**Objective:** Take the Week 3 Claude Code marketing harness and turn it into a durable marketing operating system: more skills, a memory layer that spans runs, failure alerts that page you, and a path off the laptop if uptime matters. This week expands the same Claude Code + vault + Composio system. It does not require installing Hermes or a different agent framework.

---

## Key Concepts Covered
- Why a one-skill harness is a demo and an operating system is something you can ignore until it pings you
- Memory that spans runs: the run log and an insights log as long-term and recent memory
- Multiple skills in one harness (competitor-watch, campaign-retro, content-brief)
- Failure alerts and permission hardening (reporting skills never post without approval)
- Off the laptop: when uptime matters, a always-on machine or cloud runner, with the vault and skills traveling with you
- The local marketing library as optional capability (marketing-plan, marketing-ideas) used as reference, not bolted on as weekly jobs

## Deliverable
**Marketing Operating System**: the Week 3 harness now with spanning memory, at least two skills, failure alerts, and a durable schedule. Same vault, same Claude Code, bigger surface.

## Prerequisites
- Your Week 3 harness: CLAUDE.md, the weekly-marketing-insights skill, Composio connected, reports/weekly/ with a run log, and a Monday 08:00 schedule
- At least two weekly reports already produced so the memory layer has something to learn from
- No Hermes install required
