# Week 4: Hermes Agent — Autonomous Marketing Operations

**Session Length:** ~3 hours
**Objective:** Deploy a persistent AI agent that knows your brand, remembers past work, learns from feedback, and executes multi-step marketing tasks independently.

---

## Key Concepts Covered

- What Hermes Agent is: an open-source agent framework by Nous Research
- Persistent memory: brand voice, buyer personas, competitive intel
- Skills: reusable marketing procedures (Competitive Analysis, Content Brief, Campaign Retro)
- Multi-platform delivery: Slack, Telegram, email, terminal
- Hermes + n8n integration patterns
- Orchestration: when one agent isn't enough
- Production: cost management, reliability, security, team rollout

## Deliverable

**Brand Intelligence Agent** — A live Hermes instance with brand memory, 3 marketing skills, and n8n integration. Ready to handle real marketing workflows.

## Prerequisites

- Hermes Agent installed (`pip install hermes-agent`)
- Claude API key ready
- 1 recurring marketing task you'd like an agent to handle
